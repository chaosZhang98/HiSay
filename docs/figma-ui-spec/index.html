4. Figma 落地规范（复制到 Figma 时必须做的 5 件事）

#事项怎么做为什么重要
1建立 Local Variables（同 theme.ts 命名）Variables → Color / Number 按 §1 逐 token 建立；颜色命名空间 color/light/* 和 color/home/*；圆角 radius/sm~full；字号 type/header, body, caption, small；间距 space/xs~xlTokens 单一真相源，后续改 design 直接同步 RN theme.ts，不再两边改魔法值
2Frame 统一尺寸：390 × 844（iPhone 14）所有 Screen 基于一个 Master Frame；图层分：Dynamic Island / Status Bar / Safe Top 54 / Content / Safe Bottom 34避免各屏画框大小不一；开发者拿到 1:1 标注可直接实现
37 个组件全部做成 Component Set按 §3 规格建立 Component Set + Variants（如 Button / Type=Primary|Ghost-Blue|Ghost-Red · State=Default|Pressed|Disabled）后续新增页面直接拖拽复用；UI 改动一处全文件同步
4Auto Layout + 8pt Grid 强制启用所有列表/卡片/顶栏使用 Auto Layout（H/V）；Padding、Gap 全部从 space tokens 取，禁止 3/5/7 等奇数间距和 RN 代码 StyleSheet 的 spacing tokens 完全对齐；降低「Figma 13px、代码 12px」这类随机偏差
5两主题隔离的 Style Library在 Figma 中建立 Light Style / Home Style 两套 Color Style；主页组件必须使用 Home Style；聊天/任务/小程序页必须使用 Light Style；禁止混用避免在同一页面随机出现深/浅色风格不一致；保持主页深、聊天浅的双主题契约
