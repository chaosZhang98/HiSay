# Mobile 端配色方案规范（COLOR SPEC）

> 适用于 `apps/mobile`（Expo / React Native / Tamagui）。
> 本文档描述本次全面配色优化的完整方案：设计目标、三层级色表（HEX / RGB / HSL）、应用规范、前后对比效果与 WCAG 2.1 AA 对比度核验数据。

---

## 1. 设计目标

原配色整体偏「沉重、压抑」：主页为深黑壳（`#0A0A0A`），大面积深色造成视觉负担；文字、链接、按钮多处使用低对比或高亮白字，观感生硬。

本次重构目标：

- **轻盈现代**：用暖米白 + 暖橙作为品牌主色，营造明亮、舒适、有呼吸感的基础层。
- **符合色彩理论**：按 「主色调 · 辅助色 · 中性色」 三层级组织，明确每个色值的职责与应用场景。
- **可访问性**：所有文字/图标的关键组合对比度达到 **WCAG 2.1 AA**（正文 ≥4.5:1，大字号/图标 ≥3:1）。
- **多设备适配**：中性色采用暖灰棕梯度，在 OLED / 高色域 / 普通 LCD 上均能稳定呈现，避免纯白过亮与纯黑死黑带来的过曝或发灰问题。
- **风格统一**：所有颜色收敛到 `theme.ts` 设计令牌，业务组件不再散落硬编码颜色。

---

## 2. 设计原则

1. **橙底配深字，绝不配白字**
   白字 on 主橙仅 `2.35:1`（不达 AA）。所有 `primary` 背景上的文字 / 图标一律使用 `onPrimary`（`#3A2208`，`6.34:1`）。

2. **文字三层级**
   `textPrimary > textSecondary > textTertiary`，分别对应主标题、正文/次级、弱化/占位，保证信息层级清晰且全部 ≥4.5:1。

3. **语义色自带 Soft 底**
   每个语义状态色（success/warning/danger/info）都配一个同色相、低饱和度的 `Soft` 背景，用于状态标签、徽标、提示条，避免直接大面积使用高饱和色。

4. **装饰性分隔线从轻**
   边框/分割线采用低对比暖灰，避免过重的视觉分割；可交互控件的边界则用更高对比度色。

5. **主页独立浅色调**
   空会话主页单独定义 `home.*` 子集，从原深黑壳切换为浅暖米，保持页面明亮、轻盈、无压抑感。

## 4. 色彩应用规范

### 4.1 文字层级与对比度（关键组合，均已 ≥4.5:1）

| 组合 | 对比度 | 级别 | 说明 |
|---|---|---|---|
| `textPrimary` on `card` | 9.84:1 | AA / AAA | 主标题、正文 |
| `textPrimary` on `background` | 8.92:1 | AA / AAA | 页面主文字 |
| `textSecondary` on `card` | 5.89:1 | AA | 次级、说明 |
| `textSecondary` on `background` | 5.34:1 | AA | 次级文字 |
| `textTertiary` on `card` | 5.28:1 | AA | 弱化、占位 |
| `textTertiary` on `background` | 4.78:1 | AA | 弱化文字（最低档，仍达标） |
| `primaryDeep` on `card` | 5.22:1 | AA | 链接、强调 |
| `primaryDeep` on `background` | 4.72:1 | AA | 链接（浅底） |
| `primaryDeep` on `primarySoft` | 4.71:1 | AA | 标签内强调 |

### 4.2 主色 `primary` 底上的文字规则

| 组合 | 对比度 | 结论 |
|---|---|---|
| **白字** on `primary` | **2.35:1** | ❌ 不达 AA，禁止使用 |
| `onPrimary` on `primary` | 6.34:1 | ✅ 推荐 |
| `onPrimary` on `primaryPressed` | 5.18:1 | ✅ 推荐（按压态） |

> **强制规则：所有 `primary` / `primaryPressed` 背景上的文字与图标一律用 `onPrimary`（`#3A2208`），禁止白字。**

### 4.3 语义色应用规范

| 状态 | 图形/文字色 | 推荐底色 | 对比度（文字 on Soft 底） |
|---|---|---|---|
| 成功 | `success` | `successSoft` | 4.61:1 ✅ |
| 警示 | `warning` | `warningSoft` | 4.69:1 ✅ |
| 错误 | `danger` | `dangerSoft` | 4.76:1 ✅ |
| 信息 | `info` | `infoSoft` | 4.54:1 ✅ |

> 使用方式：状态文字用深语义色，状态标签背景用对应 `Soft` 色，避免大面积高饱和底色。

### 4.4 非文本 / 装饰元素分级

| 元素 | 使用色 | 对比度 | 说明 |
|---|---|---|---|
| 装饰性分割线 | `border` | 1.18–1.31:1 | 仅作视觉分区分隔，非交互入口，刻意从轻 |
| 禁用态控件 | `disabled` | 1.71:1 | 禁用态可辨但不强调，符合通用惯例 |
| 可交互组件边界/图标 | `primary` / `primaryDeep` / `textTertiary` | ≥3:1 | 保证可辨识（WCAG 1.4.11 非文本 ≥3:1） |
